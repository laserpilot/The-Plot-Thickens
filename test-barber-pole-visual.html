Barber Pole Visual Test

Simple straight line to get the visual right before integration

Expected Pattern:

Path:     ═══════════════════════════════════════════

View along path (looking down the cylinder axis):

        SSSS          SSSS          SSSS
      SSSSSSSS      SSSSSSSS      SSSSSSSS
    ════════════════════════════════════════
      SSSSSSSS      SSSSSSSS      SSSSSSSS
        SSSS          SSSS          SSSS

S = stripe crossing perpendicular to path (like painted bands around a cylinder)
Each S-shape is ONE stripe wrapping around
Gap between stripes creates the barber pole pattern
As you move along the path, the "cylinder" rotates, showing stripe-gap-stripe

NOT like this (what I coded wrong):
Path: ═══════════════════
      ~~~~ stripe 1 ~~~~ (parallel to path)
      ~~~~ stripe 2 ~~~~ (parallel to path)
      ~~~~ stripe 3 ~~~~ (parallel to path)
