# Web V1 (Legacy)

This is the legacy standalone web interface for the Plotter Line Thickener.

**Status:** Legacy / Archived

## Notes

- Uses p5.js for rendering
- Single-file architecture (no build tools)
- Features include focus-blur, attractors, and various fill modes
- Not actively maintained

## Recommended

Use **web-v3** for new work:

```bash
cd web-v3
npm install
npm run dev
```

See [web-v3/README.md](../web-v3/README.md) for documentation.

## Running (if needed)

Open `index.html` directly in a browser. No build step required.
