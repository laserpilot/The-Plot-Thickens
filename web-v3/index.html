Hatch Gradient Options

Creates crosshatch fills with density based on simulated lighting. Lighter areas get sparser hatching, darker areas get denser fills.

Shape Fill Options

Creates sequential filled or hollow circles along paths like "peas in a pod". Circle sizes follow the envelope taper for organic, flowing patterns.
Tip: Base Offset above controls spacing between concentric circles in filled mode. Use envelope presets (Effects section) to create tapered "bead" effects.

Barber Pole Options

Creates candy cane/barber pole spiral stripes with dynamic twist and occlusion effects for 3D cylindrical illusion. Stripe width and twist rate respond to envelope taper.
Tip: Leave Stripe Height empty for auto-scaling (2mm on short paths, 10mm on long paths). Use Edge Sharpness for pointier spirals, Middle Angle for steeper slopes. Try Three-Strand Braid for complex weaving effects. Braid occlusion only works when Occlusion Mode is set to "Braid".

Curly Options

Creates a continuous looping/spring pattern that follows the path like a telephone cord or coiled spring. Loop size follows the envelope taper.

Compression/Expansion (Tonal Variation)

Modulate loop density. Compressed = tighter = darker. Expanded = looser = lighter.
Tip: Try sinTaperBoth envelope for springs that tighten at the ends. Multiple strands create a braided effect. Higher frequency = tighter coils, lower = lazy loops.

Text Fill Options

Places text along path centerlines like Illustrator's Type on Path. Text warps to follow curves and scales with the envelope.
Tip: Use sinTaperBoth envelope for text that grows and shrinks along the path. Higher compression strength creates more dramatic warping on tight curves.

Moiré Options

Creates phase-locked moiré patterns with two or more nearly-parallel stroke families. The interference bands create stable visual patterns along the path.
Tip: For classic moiré, use spacing mode with 1-3% delta. For controlled bands, use phase mode. Keep spacing tight (0.6-1.2mm) for subtle interference. Families are rendered in different colors for plotter pen separation.

Woodgrain Options

Creates parallel strands that follow the path with synchronized slow drift, like wood grain viewed from a side cut. All strands share the same drift pattern, bending together organically.
Tip: Use sinTaperBoth envelope for natural wood grain that tapers at ends. Higher band count with lower spacing creates denser grain. The drift wavelength controls how "wavy" the grain appears.

Contour Echo Options

Creates concentric inward offsets that echo the path shape, like topographic contour lines. Outer contours can be fuzzy while inner contours become crisp.
Tip: Set outer noise higher than inner noise for a "fuzzy to crisp" effect. Smaller contour spacing creates denser topographic appearance. Works best with sinTaperBoth envelope for gradual termination.
Fast Preview: Shows color-coded stroke widths (green=min, red=max) that approximate the final result. Much faster than full processing.
